# Demo script

1. Create a service product **Brightloop Pro**.
2. Create a monthly plan priced at 100 and minimum quantity 1.
3. Create a customer and a subscription; add the product line.
4. Move the subscription through Quotation, Confirmed, and Active.
5. Run the scheduled action **Brightloop: Generate recurring invoices**.
6. Open the generated native invoice and register a payment; show its reconciled state.
7. Run the scheduled action again and show that no second billing period or invoice is created.
8. Pause and resume the subscription, then close it and verify closed subscriptions are not billed.
